# TaskSwiper i18n Skill

You are an expert in Task Swiper's internationalization system. Help with adding languages, managing translation strings, and ensuring consistency.

## When to Use This Skill

- Adding new translation strings
- Adding a new language
- Updating existing translations
- Fixing missing translations
- Regenerating localization files
- Debugging locale display issues

## Translation Files

Location: `lib/l10n/`

**Current files:**
- `app_en.arb` - English (source/primary)
- `app_fi.arb` - Finnish

**Format:** ARB (Application Resource Bundle) - JSON-based format used by Flutter.

## ARB File Structure

```json
{
  "simpleString": "Hello World",
  "stringWithParam": "Hello, {name}!",
  "@simpleString": {
    "description": "A greeting displayed on the home screen"
  },
  "@stringWithParam": {
    "description": "Greeting with user name",
    "placeholders": {
      "name": {
        "type": "String",
        "format": "plain"
      }
    }
  }
}
```

### Metadata (lines starting with `@`)
- `description`: Human-readable description of the string
- `placeholders`: For parameterized strings, defines type and format

### Special Keys
- `"@@locale"`: Language code (e.g., `"en"`, `"fi"`) - included in ARB files

## Key Methods & Classes

### LanguageProvider (`lib/providers/language_provider.dart`)
- Manages current locale
- Persists preference via SharedPreferences
- Exposes `locale` getter/setter

### AppLocalizations (`generated`)
- Generated by `flutter gen-l10n`
- Access via: `AppLocalizations.of(context)!`
- Provides all translation strings as properties

## Supported Locales

Defined in `main.dart`:
```dart
supportedLocales: const [
  Locale('en'), // English
  Locale('fi'), // Finnish
],
```

## Common Tasks

### Add a new translation string

1. Add to `app_en.arb`:
```json
{
  "myNewString": "My new string",
  "@myNewString": {
    "description": "Description of this string"
  }
}
```

2. Add translation to `app_fi.arb`:
```json
{
  "myNewString": "Minun uusi merkkijono"
}
```

3. Regenerate:
```bash
flutter gen-l10n
```

### Add a new language

1. Create new ARB file: `lib/l10n/app_<code>.arb` (e.g., `app_de.arb` for German)
2. Copy all keys from `app_en.arb` and add translations
3. Add `@@locale` key:
```json
{
  "@@locale": "de",
  "appTitle": "Aufgaben Wischer",
  // ... all other keys
}
```
4. Add locale to `main.dart`:
```dart
supportedLocales: const [
  Locale('en'),
  Locale('fi'),
  Locale('de'), // New
],
```
5. Add to language selector in `lib/ui/widgets/task_list_drawer.dart`:
```dart
DropdownMenuItem(
  value: Locale('de'),
  child: Text('Deutsch'),
),
```
6. Update `LanguageProvider` if needed for default detection
7. Regenerate:
```bash
flutter gen-l10n
```

### String with parameters

1. In `app_en.arb`:
```json
{
  "greeting": "Hello, {name}!",
  "@greeting": {
    "description": "A greeting with name",
    "placeholders": {
      "name": {
        "type": "String"
      }
    }
  }
}
```

2. In `app_fi.arb`:
```json
{
  "greeting": "Hei, {name}!"
}
```

3. Use in code:
```dart
Text(localizations.greeting('John'))
```

### Plural and gender support

ARB supports ICU syntax for plurals:
```json
{
  "itemCount": "{count, plural, =0{No items}=1{One item}other{{count} items}}",
  "@itemCount": {
    "description": "Number of items",
    "placeholders": {
      "count": {"type": "int"}
    }
  }
}
```

### Regenerate localization files

Always run after modifying ARB files:
```bash
flutter gen-l10n
```

This generates Dart code in `.dart_tool/flutter_gen/gen_l10n/` (do NOT edit directly).

## Gotchas

- Always update BOTH English and Finnish when adding new strings
- The `@` prefix in ARB files is for metadata, not part of the key
- After modifying ARB files, ALWAYS run `flutter gen-l10n`
- Generated files in `.dart_tool/` are ephemeral - don't check them in
- Placeholder types matter: `String`, `int`, `double`, `bool`, `num`
- Use `AppLocalizations.of(context)!` to access (null check with `!` because context always has localizations)

## Verifying Translations

Check for missing translations:
```bash
# List all keys in English
grep -E '^\s+"[^@]' lib/l10n/app_en.arb | sed 's/.*"//;s/":.*//' | sort

# List all keys in Finnish
grep -E '^\s+"[^@]' lib/l10n/app_fi.arb | sed 's/.*"//;s/":.*//' | sort

# Find keys in English but not Finnish
comm -23 <(grep -E '^\s+"[^@]' lib/l10n/app_en.arb | sed 's/.*"//;s/":.*//' | sort) \
        <(grep -E '^\s+"[^@]' lib/l10n/app_fi.arb | sed 's/.*"//;s/":.*//' | sort)
```
